# hxyfront-62013 木构拆卸归安交接台

源提示词编号：8（古建筑木结构榫卯构件测绘）

面向古建修缮现场的拆卸—归安交接管理前台：构件按「建筑 + 编号」唯一登记，围绕交接单驱动拆卸、临时支撑、归安核验、校正与闭环全流程。

## 业务规则

- **构件唯一**：以 `建筑::编号` 为唯一键，全站清单、筛选、关系统计均以此为准。
- **拆卸保护**：拆卸前若仍有下游构件在架引用，必须先登记临时支撑，否则整次操作原子拒绝，不落库。
- **交接幂等**：每件构件至多一笔未关闭交接；重复或并发提交沿用首次结果，不重复开单。
- **危急构件**：只能按「原材更换」交接，替换件木材与截面（写法归一化后）必须与原构件一致，否则拒绝落库。
- **归安校正**：归安方向与要求不符即退回「待校正」，校正确认后才允许闭环归档。
- **状态一致**：所有变更经纯函数原子提交并写入 localStorage，关系清单、筛选、统计与刷新后状态保持一致。

## 技术栈

React + Vite + TypeScript

- `src/domain.ts` 领域模型与派生计算（下游引用、在架判定、归一化）
- `src/ops.ts` 原子操作（校验全部通过才返回新状态，拒绝即不落库）
- `src/store.ts` 单例存储 + 同步提交 + localStorage 持久化
- `src/seed.ts` 演示数据（三栋建筑、十条构件、四笔各状态交接）
